# lowlight-dn — إزالة ضوضاء الإضاءة الضعيفة على الـGPU

برنامج سطر أوامر خفيف (ملف `.exe` واحد) مكتوب بـ**Rust** وبيشغّل الحساب على كارت الشاشة عن طريق **wgpu** (Vulkan / DX12 / Metal)، فبيشتغل على NVIDIA وAMD وIntel، وعلى الـeGPU الخارجي كمان. مجاني بالكامل.

## ⚠️ حالة المشروع (بصراحة)

| الجزء | اتجرّب؟ |
|---|---|
| **الخوارزمية** (بروفايل ضوضاء + حركة + دمج زمني + wavelet) | ✅ اتقاست بأرقام على فيديو اصطناعي (تحت) |
| **منطق الـshaders** (الفهارس، تخطيط الذاكرة، الحدود) | ✅ اتترجم سطر بسطر لـC++ وطلّع نفس نتيجة المرجع (27.84 مقابل 27.88 dB) |
| **أوامر ffmpeg/ffprobe** (فك وترميز ProRes/H.265/H.264 + الصوت) | ✅ اتجرّبت فعليًا |
| **ترجمة كود Rust وتشغيل wgpu على GPU حقيقي** | ❌ **ماتجرّبش** — مفيش Rust ولا GPU عندي |

يعني أول `cargo build` ممكن يطلّع أخطاء ترجمة صغيرة، أو أول تشغيل على الـGPU يحتاج تعديل. ابعتلي نص الخطأ بالظبط وأصلحه — ده متوقع في أول تشغيل.

## التثبيت (مرة واحدة، كله مجاني)

1. **Rust**: من https://rustup.rs
2. **FFmpeg** (لازم يكون في الـPATH): على ويندوز `winget install Gyan.FFmpeg`
3. تأكد من تعريف كارت الشاشة (Vulkan أو DX12 بيجي مع تعريف NVIDIA/AMD/Intel الحديث).

```
cd lowlight-dn
cargo build --release
```
الملف الناتج: `target/release/lowlight-dn.exe`

## الاستخدام

```
lowlight-dn --list-gpus                      # يعرض الكروت (اختار رقم الخارجي)
lowlight-dn -i clip.mp4                      # ناتج: clip_dn.mov (ProRes 422 HQ)
lowlight-dn -i clip.mp4 --gpu 1 -o out.mov   # كارت معين
lowlight-dn -i clip.mp4 --codec h265         # ناتج mp4 (H.265 10-bit)
```
الناتج بتستورده في دافنشي ريزولف عادي (ProRes أنسب للتلوين). الصوت بيتنسخ زي ما هو.

## الإعدادات

| الإعداد | الافتراضي | معناه |
|---|---|---|
| `--temporal-frames N` | 3 | عدد الإطارات من كل جانب للدمج الزمني (0 = إيقاف، أقصى 8) |
| `--tau` | 2.0 | تسامح الدمج الزمني. أعلى = تنعيم أقوى، لكن خطر "ظلال" أكبر |
| `--spatial` | 1.0 | قوة التنعيم المكاني (0 = إيقاف) |
| `--chroma` | 1.0 | مضاعف إضافي لضوضاء الألوان |
| `--noise-scale` | 1.0 | لو الضوضاء لسه باقية ارفعه (1.3)، ولو الصورة بلاستيك قلّله (0.8) |
| `--profile-pairs` | 4 | عدد أزواج الإطارات لقياس الضوضاء |
| `--codec` | prores | `prores` / `prores444` / `h265` / `h264` |

البرنامج بيقيس الضوضاء **أوتوماتيك** من أول إطارات الفيديو (زي ما Neat Video بيعمل بالـnoise profile)، فمش محتاج تختار منطقة يدويًا. أحسن النتايج لما أول ثانية في الفيديو فيها مشهد عادي (مش قطع مشهد).

## إزاي بيشتغل

1. **بروفايل الضوضاء**: بيقيس الضوضاء من الفرق بين إطارين بعد تعويض الحركة (المحتوى بيلغي نفسه والضوضاء بس هي اللي تفضل)، لكل قناة (Y/Cb/Cr) ولكل مستوى تفاصيل ولكل درجة سطوع.
2. **تقدير الحركة**: بحث بلوكات هرمي (1/4 دقة ← دقة كاملة ← ربع بكسل).
3. **دمج زمني**: متوسط مرجّح لـ7 إطارات متراصفة؛ الوزن بيقل أوتوماتيك لو في عدم تطابق (فمفيش ظلال حوالين الأجسام المتحركة).
4. **تنعيم مكاني**: تحليل wavelet (a-trous) بـ5 مستويات، وعتبات مبنية على البروفايل ومعدّلة بحسب كام إطار اتدمج.

الأسلوب نفسه من نفس عائلة اللي في Resolve (Temporal/Spatial NR) وNeat Video، لكن دي **أدوات مغلقة المصدر** ومش هقدر أقول إن النتيجة مطابقة لها؛ ده تنفيذ مستقل للطرق المنشورة.

## نتايج التحقق (فيديو اصطناعي: حركة كاميرا + جسم متحرك + ضوضاء ضعيفة الإضاءة)

شغّل `python reference/validate.py` (محتاج numpy وscipy وopencv):

| مستوى الضوضاء | قبل | بعد | تحسّن |
|---|---|---|---|
| ×0.5 | 22.72 dB | 32.11 dB | +9.4 dB |
| ×1.0 | 18.09 dB | 27.88 dB | +9.8 dB |
| ×2.0 | 14.46 dB | 24.28 dB | +9.8 dB |

⚠️ ده فيديو اصطناعي؛ الأرقام مش وعد بنفس الأداء على فيديو موبايل حقيقي (ضغط H.264، ضوضاء مش بالشكل المفترض). أول اختبار حقيقي هيحتاج ضبط `--noise-scale` و`--spatial`.

للتحقق من الـshaders: `g++ -O2 -std=c++17 reference/kernels_cpu.cpp -o /tmp/kernels_cpu` ثم `python reference/check_kernels.py`.

## حدود معروفة

- فيديو بطيء الحركة أو ثابت بيدّي أحسن نتيجة. حركة سريعة جدًا (أكتر من ±24 بكسل بين إطارين) بتقلّل الدمج الزمني.
- الأبعاد لازم تكون زوجية. المعالجة 16-bit داخليًا لكن مصدر الموبايل 8-bit، فممكن يظهر banding خفيف في السماء — ProRes 10-bit بيساعد.
- مفيش تحسين سرعة لسه (الدمج الزمني هو الأتقل). السرعة الفعلية على كارتك مش مقاسة.
- الفيديو متغيّر معدل الإطارات (VFR) بيتعامل معاه كمعدل ثابت.
- مفيش Pre-built exe: لازم تبنيه بنفسك (خطوة واحدة فوق).
